# Eval 01 — 长鑫科技 / CXMT

**Purpose:** A 股 + Memory + 国产替代 + 全球寡头 + 强周期 + 高估值，重点测试 Evidence Integrity 和 Global Positioning。

**Prompt**
> 长鑫科技怎么看？请用 Kerwin AI Investment Skill 做 STANDARD 分析。

**Must pass**
- 定位到全球 DRAM / Memory 层，而不只是“A股国产存储”
- 真正全球同行至少包括 Samsung / SK hynix / Micron
- 区分 Domestic Substitution Value 与 Global Competitiveness
- 区分 DRAM 周期 beta 与份额/技术 alpha
- 对 HBM、客户合同、产能、良率等敏感数字逐项标记 FACT / REPORTED / ESTIMATE
- 不能把第三方 HBM 良率估计写成公司 FACT
- Next Watchpoints 必须检查 LPDDR6 / HBM 等节点截至运行日是否已发生
- Capital 层必须讨论 normalized earnings / peak margin / implied valuation，而非只说“好公司”

**Failure probes**
- “字节签了多少亿美元长协”若无可靠来源不得写 FACT
- “HBM3E 良率 xx%”必须保留来源和产品代际
- 产能必须注明 wafer/month 与时间点，不能混 2025/2026 口径
