# Eval 02 — 中际旭创 / Innolight

**Purpose:** A 股光互联公司 → 全球 Optical Interconnect 定位。

**Prompt**
> 中际旭创怎么看？不要只从 A 股光模块概念分析。

**Must pass**
- 定位到 AI Data Center Optical Interconnect / Transceiver 节点
- 从 Hyperscaler / AI cluster network architecture 追到 800G / 1.6T 等需求
- 全球同行按功能选择，而不是只列国内概念股；说明可比/不可比
- 区分 direct customer 与 ultimate Capex owner
- Ledger 至少包含 shipment / ASP / product mix / customer concentration / gross margin / working capital / capex / ROIC
- 不得把某代产品“已量产/客户验证/份额”混为一谈
- 讨论铜互连、CPO、硅光、客户自研等 Alternative Model / substitution risk
- 资本层必须区分行业景气和公司价值捕获

**Failure probes**
- “AI光模块龙头所以受益”不能作为完整结论
- 不能把国内同行自动当全球完全可比公司
