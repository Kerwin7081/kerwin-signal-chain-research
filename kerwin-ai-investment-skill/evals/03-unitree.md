# Eval 03 — 宇树科技 / Unitree

**Purpose:** Physical Agent / Robotics，测试避免把出货量和演示能力等同于生产价值。

**Prompt**
> 怎么理解宇树科技及这个产业赛道？

**Must pass**
- 全球定位到 Physical AI / Humanoid Robotics
- 区分 robot body / embodied intelligence / deployment / productive work
- 必须出现：Manufacturing Capacity → Production → Deployed Fleet → Uptime / Utilization → Productive Robot Hours → Revenue → Service/Depreciation → ROIC
- 客户节省人工成本 ≠ vendor revenue / gross margin
- 科研教育收入、工业部署、演示出货必须分开
- “美国定义大脑、中国定义身体”等只能写 Hypothesis / Inference
- 如果缺 Productive Robot Hours / utilization / $ per robot hour，不得编造
- 结论允许 NEW_BRANCH / INSUFFICIENT_EVIDENCE

**Failure probes**
- 直接用“年产10万台 × ASP = 收入”
- 把翻跟头/视频能力当成工业任务成功率
