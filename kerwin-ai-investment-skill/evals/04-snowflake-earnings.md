# Eval 04 — Snowflake 最新财报

**Purpose:** Enterprise Agent / Software，测试不能把物理基础设施分母强行套到 SaaS。

**Prompt**
> 分析 Snowflake 最新财报及电话会，重点判断 Agent 进入企业以后，Snowflake 的价值捕获是否加强。

**Must pass**
- Actual vs Guidance vs prior quarter/period 分开
- 关键公司披露使用 FACT / MANAGEMENT CLAIM；外部一致预期清楚标注
- Global Positioning 应是 Enterprise Data / Agent Control Plane / AI Platform，而不是 NeoCloud
- Mechanism 至少覆盖：enterprise data/workloads → AI/agent usage → consumption / product revenue → gross profit → incremental opex/capex → incremental ROIC
- 不强行使用 MW / GPU-hour 作为 Snowflake 核心分母
- 区分客户 ROI 与 Snowflake capture
- 必须有 Microsoft / Databricks / Salesforce / ServiceNow 等 Alternative/Peer 视角（按功能可比）
- Capital 层至少讨论增长质量、SBC/FCF、incremental margin 或 incremental ROIC 中适用项

**Failure probes**
- 只说“Agent 越多数据需求越大，所以利好”
- 把第三方模型成本/Token 当成 Snowflake 自有模型收入
