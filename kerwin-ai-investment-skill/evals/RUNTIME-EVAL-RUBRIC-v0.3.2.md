# Runtime Eval Rubric — v0.3.2

每个案例 20 分，10 个维度，每项 0–2 分。

| Dimension | 2 分标准 |
|---|---|
| Decision Question | 将表面问题重构成可投资检验的问题 |
| Reality | 关键事实充分，日期/口径明确 |
| Evidence Integrity | FACT/ESTIMATE 等分类正确；重要数字有 provenance |
| Global Positioning | 正确产业层级、全球同行、最终需求源 |
| Mechanism | 完整传导链，不跳步 |
| Ledger | 找到 3–6 个真正状态变量 |
| Economics / Capital | 单位经济、现金流、ROIC/WACC/估值至少适用项做实 |
| Model Competition | Base + Alternative + Disconfirming Evidence |
| Judgment | 基本面与股票价格/Thesis Impact 分开 |
| Falsification / Freshness | 至少 2 条可检验证伪；Watchpoints 经过 freshness check |

## Critical Failure

出现任何一项，单案例最高不超过 12/20：
- 将未经验证合同、技术节点或产能写成 FACT
- 为完成模型编造关键数字
- 把 announced / contracted / active / utilized / realized 混为一谈
- 用“受益 AI / 国产替代 / 龙头”替代机制和经济账
- 把已经发生的事件继续列为未来 Watchpoint
- 只在本地概念股里比较，不做全球功能定位（本地公司案例）

## Runtime Record

每次运行记录：
- Runtime
- Underlying model（如果可见）
- Skill version
- Run date/time
- Prompt
- Score /20
- Critical failures
- Missing evidence
- Notable wording drift
