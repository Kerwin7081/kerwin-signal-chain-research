## No Critical Failure Triggered

The report does not fabricate missing robot-hours or contracts, and it distinguishes FACT / MANAGEMENT CLAIM / ESTIMATE / CALCULATION. However, it does not fully satisfy the Physical Agent eval’s central requirement to make `productive robot hours` and customer ROI the main economic bridge.

## Material issues

1. **2025 “全球第一” needs SOURCE CONFLICT treatment.** Company / some trackers support it, while independent trackers can rank AgiBot ahead depending on methodology. Historical rank should not be treated as an uncontested fact.
2. **“万台级人形出货” is overstated.** The report itself cites >5,500 humanoid units for 2025. Do not convert all-robot / cumulative volume into humanoid commercial shipments.
3. **“扣非净利率近乎腰斩” is too strong.** ~34.8% → ~21.2% is a ~13.6ppt / ~39% relative decline, material but not literally near half.
4. **Reverse Expectations calculation is inconsistent.** If current market cap is ~RMB 214.5bn, required return 10%, terminal PE 25×, and terminal year is ~2035, sustainable terminal earnings should be much higher than RMB 8.5–10bn because the current equity value must compound at the required return before applying the terminal multiple.
5. **Physical Agent bridge is incomplete.** The report should explicitly ask for / mark UNKNOWN: deployed fleet, uptime, productive robot hours, customer payback, repeat purchase, service/software revenue, maintenance burden and depreciation.
6. **Unsupported market-flow wording.** “机构出逃散户接盘” is inference, not established by turnover alone; it should be labeled or removed.
