# Public Examples

## Earnings
不要停在“AI server revenue 增长，所以利好”。

```text
orders → backlog → shipment → revenue → gross margin → working capital → FCF → ROIC
```

行业需求可以加强，同时公司自身的价值捕获减弱。

## AI Infrastructure Contract
不要把 multi-GW 合同直接当作未来 realized revenue。

```text
contracted demand → financing / construction → energized MW → installed compute → utilization → realized revenue → FCF → ROIC – WACC
```

## Physical Agent
不要把 factory nameplate capacity 直接乘价格得到收入。

```text
factory capacity → actual production → deployed robots → uptime → productive robot hours → vendor revenue → service / depreciation → margin → ROIC
```

客户劳动成本节省 ≠ vendor revenue ≠ vendor gross margin。
