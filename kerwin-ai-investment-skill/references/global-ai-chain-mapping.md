# Global AI Chain Mapping

目标：把 A 股、港股及其他区域市场的 AI 公司放回全球 AI 产业链进行功能定位、同行比较、需求追踪和价值捕获分析。

核心原则：
**Global Ontology, Local Reality｜全球产业框架，本地经营现实。**

## 1. 全球功能层
Energy / Power / Data Center / GPU-ASIC / Memory-Packaging / Network / Optical / Storage / Cloud / Model / Agent / Physical AI / Application.

## 2. 必答问题
- 它在全球 AI 产业链哪一层？
- 真正解决什么 bottleneck？
- 最终需求由谁的 Capex / 订单 / 使用量驱动？
- direct customer 和 ultimate Capex owner 是否相同？
- 全球真正同行是谁？可比与不可比维度是什么？
- 价值通过份额、价格、毛利、服务、软件还是资本效率捕获？
- 本地客户、政策、出口限制、国产替代、融资成本和估值环境如何修正全球 benchmark？

## 3. Global Peer Mapping Ledger
AI Chain Layer / Core Function / Technology Generation / Ultimate Demand / Customer Mix / Global Position / Revenue Growth / Gross Margin / Capex / Working Capital / ROIC / Bottleneck / Domestic Substitution / Policy Constraint / Valuation.

## 4. 两个问题必须分开
**Global Competitiveness**：全球客户、技术、份额、成本和产品代际是否有竞争力？
**Domestic Substitution Value**：本地政策和供应链安全带来的订单是否能转化为持续收入、利润、现金流和 ROIC？

不要自动把国产替代视为全球竞争力。

## 5. 光互联示例链
Global AI cluster scale / network architecture
→ switch bandwidth / optical links
→ relevant optical generation demand
→ module / component content and share
→ supplier orders / shipment / ASP
→ gross margin / working capital / capex
→ FCF / ROIC

不要只比较 A 股“光模块概念股”，应寻找全球业务真正可比的同行。
