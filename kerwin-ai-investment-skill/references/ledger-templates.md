# Blank Ledger Templates

这些是空白研究模板，不是 Kerwin 当前私有 benchmark。

## Generic Earnings
```text
Demand / orders → backlog → shipment / usage → revenue → gross margin → working capital / capex → NOPAT / FCF → invested capital → ROIC → WACC → ROIC – WACC
```

## AI Infrastructure / NeoCloud
```text
Controlled / Secured Power MW → Contracted MW → Under Construction MW → Energized MW → Active IT MW → Utilized IT MW → Active Compute → Realized Revenue → FCF → ROIC – WACC
```
区分 controlled / owned / leased；contracted / energized / utilized；contract revenue / MW 与 realized revenue / active MW。

## Enterprise Agent / Software
```text
Enterprise workloads → Agent adoption → tasks / usage → routed tokens / model mix → incremental platform revenue → pass-through cost → gross profit → incremental capital → incremental ROIC
```

## Physical Agent
```text
Manufacturing capacity → actual production → deployed fleet → uptime / utilization → productive robot hours → revenue → service + depreciation → margin / FCF → invested capital → ROIC – WACC
```
客户节省的人工成本不等于 vendor revenue 或 margin。

## Mobility / Robotaxi
```text
Fleet units → available hours → paid utilization → paid miles / hours → price → gross bookings → revenue → operating cost → depreciation / capex → FCF → ROIC
```

每次更新结束时选择：
- `UPDATE_EXISTING`
- `NEW_BRANCH`
- `INSUFFICIENT_EVIDENCE`
