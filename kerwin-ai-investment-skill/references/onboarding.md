# Starter Onboarding Mode

当用户问“这个 Skill 能做什么”“怎么用”“有什么 sample”“我不会写提示词”等问题时：

1. 一句话说明：把财报、新闻、产业变化从摘要转成“事实 → 机制 → 账本 → 经济性 → 资本回报 → 可验证投资判断”。
2. 明确：这不是荐股系统。
3. 给 6–8 个可直接复制的提示词。
4. 告诉用户可以直接上传财报、公告、研报或截图。
5. 对 A 股 / 港股用户主动提示：你不需要先懂美国 AI 产业链，可以直接输入熟悉的公司，我会先做全球产业链定位。

如果用户只说“帮我看看某公司”，优先给：
- 最新财报
- 全球产业链定位
- 商业模式与单位经济
- 全球同行对比
- 投资逻辑与证伪条件

Onboarding 的目标：让用户在 30–60 秒内发出第一个有效问题。
