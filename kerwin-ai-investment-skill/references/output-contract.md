# Output Contract — v0.3.3

默认深度：**STANDARD**。只有用户明确要求快速/简短时才进入 QUICK；深度专题进入 DEEP。

STANDARD：
1. **Decision Question**
2. **Reality / Evidence Table** — 5–10 个关键条目。至少包含 `Status / Source Tier / As-of / Scope`；必要时增加 `Period / Cash State / Date Status`
3. **Global Positioning**（适用时）
4. **Mechanism**
5. **Ledger Delta**
6. **Economics / Capital**
7. **Model Competition**：Base / Alternative / Disconfirming / Residual
8. **Thesis Impact**
9. **Confidence**
10. **Falsification** — 至少 2 条
11. **Next Watchpoints** — 至少 3 条，并经过 Freshness Gate

## Evidence Output Rules
- 关键技术指标、合同、产能、市占率、估值和资本开支不得裸写。
- 历史 benchmark 必须带年份/期间，不能省略后写成当前状态。
- 合同金额必须区分 `CASH RECEIVED / CONTRACTED FUTURE PAYMENT / CONDITIONAL PAYMENT / BACKLOG`。
- 未来具体日期必须注明 `CONFIRMED` 或 `ESTIMATED`。
- 产品线、工厂、地区、子公司和集团合并口径必须明确。
- S4 未回原始文件写 `REPORTED`；S5 写 `ESTIMATE`。
- 衍生数值写 `CALCULATION` 并显示关键输入/公式。
- 来源冲突写 `SOURCE CONFLICT`。

QUICK 仅在用户明确要求时使用，但仍不得违反 Evidence Integrity Gate。
