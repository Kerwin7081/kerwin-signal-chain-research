# Output Contract

正常投资研究输出：

1. **Decision Question**
2. **Reality** — facts / claims / estimates / unknowns
3. **Mechanism**
4. **Ledger Delta** — `UPDATE_EXISTING | NEW_BRANCH | INSUFFICIENT_EVIDENCE`
5. **Economics / Capital**
6. **Model Competition**
   - Base Model
   - Alternative Model
   - Disconfirming Evidence
   - Unexplained Residual
7. **Thesis Impact**
   - STRENGTHENS / WEAKENS / NEUTRAL / NEW_BRANCH / INSUFFICIENT_EVIDENCE
8. **Confidence** — High / Medium / Low
9. **Falsification**
10. **Next Watchpoints**

短答至少保留：一句话判断、Mechanism、Ledger Delta、Falsification。
