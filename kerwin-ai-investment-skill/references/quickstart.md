# Quick Start Guide

你不需要会写复杂 Prompt。

最简单的开始方式：
- 上传一份财报，然后问：`这份财报最重要的投资含义是什么？`
- 输入一条新闻，然后问：`这条新闻真正改变了什么？`
- 输入一家 A 股/港股公司，然后问：`请先把这家公司放到全球 AI 产业链中定位。`

研究路径：
`Reality → Global Positioning（如适用） → Mechanism → Ledger → Economics → Capital → Judgment → Falsification → Next Watchpoint`

对本地公司使用：
**Global Ontology, Local Reality｜全球产业框架，本地经营现实。**

这不是荐股系统。它提供研究程序、产业定位、证据纪律和资本回报分析，不替用户自动执行交易。
